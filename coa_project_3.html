Boolean expressions for the control signals

Each cycle of the instruction has its own Boolean-expression table below. Signals that appear in more than one cycle (for example C0, which drives the address bus in both Fetch and Interrupt) get a separate expression in each cycle — the union over all cycles is the signal's overall Boolean function. The tick variable tN is numbered continuously across the whole micro-program (t1 = first tick, t2 = second, …), so expressions are unambiguous.

The cycle headings also show the phase-relative labels used in the lecture (F1, F2, F3 for Fetch, I1, I2, I3 for Indirect, E1, E2, … for Execute, IN1, IN2, IN3 for Interrupt — see PPT Slide 32), so you can compare directly. A control signal is switched on when any of its ticks is active, so its expression is the OR (written +) of those ticks.

What each box does

The meaning of C0 to C13 follows how the lines are drawn in the figure. Textbooks number them differently, so check yours. The register file, the memory column, the flag register and the dashed control-unit paths are additions that let this page run real instructions such as MOV AX,BX or STC. Real instructions are binary; the readable text is shown instead so you can follow it. Boolean expressions use the continuous t* tick names so they can be compared directly with the textbook's control-unit equations; the phase-relative labels (F*, I*, E*, IN*) are shown alongside in the cycle headings.
